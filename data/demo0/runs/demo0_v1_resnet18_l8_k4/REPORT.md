# V²-DiT Demo 0 结果报告

## 结论

Demo 0 的工程输出已完成并通过审计，但当前 **B5 还没有达到计划 1.0 的进入视频模型条件**。

- 在 `非对称建筑平动` 上，B5 的 provisional 代理总分为 **0.7203**，优于等参数 B4 的 **0.6818**；PCK@1 为 **0.8515**，EPE 为 **0.6827 token**。
- 在 `简单平动透视关系` 上，B5 的代理总分为 **0.3845**，低于 B4 的 **0.4648**；PCK@1 为 **0.3171**，EPE 为 **5.3620 token**。
- `B5_posthoc_only` 与完整 B5 的分数几乎相同（简单片段 0.3870 vs 0.3845；非对称建筑 0.7197 vs 0.7203），因此当前数据还不能证明“稀疏 value 路由”本身带来稳定收益。
- 固定 `K=4,L=8` 不是两段数据上的一致最优值：简单片段的 K=8 较好，非对称建筑的 K=2/L=4 较好。

按计划第 13 节的停止/转向条件，当前应停在 Demo 0，不进入 CamI2V/VACE 集成。下一轮应先提高简单片段的 Top‑8 候选覆盖、校准拒绝覆盖率，并用 depth/visibility 得到几何真值后再判断方向是否成立。

冻结编码器为 ImageNet ResNet‑18 `layer3`，固定随机投影到 64 维；每个查询 token 保留 L=8 个候选；完整 V² 使用 K=4 个二维平移槽和一个拒绝槽。B4 与 B5 均为 1410 个可训练参数，避免把参数量差异当作结构收益。未使用 VACE checkpoint，也未生成新视频。

现有数据没有 depth、visibility 或 entity mask。PCK/EPE/Top‑8/Reject 指标来自 OpenCV DIS 双向光流弱代理，只能用于调试和相对比较；这里的 `Provisional-Demo0-Proxy-Score` 不是计划中有几何真值的正式 `Demo0-Score`。

## 可视化产物

每个 clip 均包含两种查看方式：

1. 可交互前后端：`backend/app.py` + 已构建的 `frontend/dist/`。页面支持 run/视频/帧/token/Top‑K/透明度选择，点击当前帧直接选 token，显示首帧稠密相似度热力图、Top‑L、验证后 value 权重、运动槽、拒绝概率和置信度。
2. 与原视频等长的逐帧 overlay：`overlays/000000.png ...` 是 Hungarian 稳定后的离散 slot 配色，`overlays/flow/000000.png ...` 是方向/幅值配色；对应 MP4 为 `overlay_preview.mp4` 与 `overlay_flow_preview.mp4`。

另外，每个 clip 的 `query_heatmaps/` 保存 3 个代表 token 的静态查询图，可直接打开，不需要启动网页。

## 审计

`audit.json` 已验证：

- 两组完整帧数分别为 720 和 882；
- 两类 PNG 序列和两类 MP4 均与各自原视频严格等长；
- `topl_index/topl_weight/slot_assignment/reject_prob/motion_vectors/token_confidence/slot_id/slot_prob/pred_ref_xy` 形状正确且边界帧为有限值；
- B0–B5、十项关键消融和所有要求指标均存在；
- 指标保留 provisional 标记。

## 相对计划 1.0 的未满足项

这些不是静默省略，而是由当前两组输入决定的明确边界：

- 用户本轮指定只使用两段视频，因此没有声称覆盖计划中的 A–F 六类独立场景，也没有固定的跨世界训练/测试划分。
- 当前录制没有 depth、visibility、entity mask 或人工点真值；DIS 仅替代为自动弱代理。因此不能给出正式几何 `Demo0-Score`，也不能据本结果宣称精确对应已成立。
- Demo 0 没有扩散去噪步和插入层，故噪声等级/DiT 插入层消融记录为不适用；它们属于 Demo 1。交互页只暴露真实存在的 `step=0 / resnet18.layer3 / single_projection`，没有伪造选择项。
- 没有调用 CamI2V 或 VACE checkpoint；根据停止条件，在补齐真值并消除简单场景退化前不应进入视频生成阶段。
