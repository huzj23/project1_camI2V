## 1. 为什么要重筛

本项目的输入不是一张图，也不是一段已经拍好的视频，而是**同一静态场景的两张真实端点图** `(I0,I1)`；输出是相机从 `I0` 视点平滑移动到 `I1` 视点时应看到的中间视频。教材中的算法只有在这个输入—输出关系下仍然成立，才可能成为架构先验。

本附录给每个知识点做三个检查：

1. **双端必要性**：删掉 `I1` 后，这个先验是否失效或明显变弱？如果分别对两图运行同一个单图算法，答案是否定的。
2. **观测合法性**：推理时只能把 `I0`、`I1` 当真实观测。生成的中间帧可以作为网络状态，不能被当成新的摄影测量观测。
3. **内容作用**：它是否能改变中间帧的对应、三维结构、遮挡、表面或成像采样？只规定平滑轨迹属于基础设施，不是主要创新。

结论分为四类：

- **核心**：可直接形成双端点架构假设；
- **组件**：只能服务于核心方案；
- **专项**：仅适合建筑、平面或特殊相机等子集；
- **排除**：原始输入条件不满足，或与任务关系过弱。

## 3. 七个保留方向的原始问题、输入输出与本项目作用

| 方向 | 原知识原来解决的问题 | 原始输入 → 输出 | 现在希望增强什么 | 两端为什么缺一不可 |
|---|---|---|---|---|
| H1 概率三维锚点＋分轴路由 | 双目三角化、遮挡推理和 Bayes 拒识 | 两图匹配与相机 → 带误差的 3D 点；证据 → 两端来源可见性、一致度、3D 置信度 | 中间帧每个区域该读首端、尾端、两端、处理冲突还是生成 | 只有对比两端的投影、可见性和残差，才能可靠生成这些路由量 |
| H2 双端重投影残差校正 | 教材 §19.14 用两端重投影误差优化三角点；bundle adjustment 是其现代多视图扩展 | 双视图测量＋初值 → 更一致的 3D 点/投影 | 在 VACE 隐层内纠正会导致两端投影不闭合的几何状态 | 残差同时相对 `I0` 和 `I1` 定义；去掉一端就不能检查闭合 |
| H3 材质边缘/遮挡轮廓分路 | 边界解释和遮挡次序 | 两图边缘与局部对应 → 材质边、轮廓边及前后关系 | 材质点沿表面搬运；轮廓随视角重新产生，避免把背景粘到前景边缘 | 边界是否跨视角保持对应必须由两端共同判断 |
| H4 深度—法线共享表面反馈 | 教材讨论法线、深度和表面连续；有限步可积求解是本文据此提出的现代架构扩展 | 多视图几何/法线线索 → 一个相容表面 | 减少墙面鼓包、立柱弯曲和相邻帧表面漂移 | 两端要投影到同一个表面；两份互不相干的单目深度不够 |
| H5 双端闭合刚性流 | 静态场景中由相机和深度计算像素运动 | 深度＋相机轨迹 → 逐帧投影流 | 给去噪块一个从首端前推、从尾端后推且在每个时刻会合的位移场 | 前向场只保证从首端出发；尾端反向场负责到达真实终点 |
| H6 投影足迹采样 | 教材给出重采样、滤波和透视纹理基础；投影 Jacobian/椭圆足迹是现代图形学与神经渲染扩展 | 连续图像、滤波核和局部投影 → 正确采样图 | 在缩小、斜视、纹理密集处稳定读取端点特征，减少闪烁和摩尔纹 | 两端观察同一表面的清晰度不同，需比较足迹后选择或融合最佳观测 |
| H7 平面＋离面视差 | 教材给出平面单应和立体视差；plane-plus-parallax 分解是现代扩展 | 两图匹配/相机 → 主平面映射与剩余视差 | 让建筑墙面稳定，同时保留窗框、檐口、柱子等凸出结构 | 平面单应和残差都由图对建立，单图不能给出跨视角视差 |

## 4. 明确排除或降级的教材知识

| 知识 | 原始条件 | 为什么不能成为默认双图主线 |
|---|---|---|
| 光度立体 | 固定相机下，同一物体被多个已知方向光源照明 | 两端图改变的是相机，光源通常未知；输入条件不同 |
| 结构光 | 主动投射已知光纹，再从变形恢复深度 | 普通 RGB 照片没有投影器编码 |
| 单图明暗恢复形状 | 单图、反射/光源等强假设 | 可作弱先验，但没有利用第二端点；还易把材质变化误判为形状 |
| 单图纹理梯度推形状 | 重复且规则的纹理及投影假设 | 场景普适性低，也不天然联合两端 |
| PnP/P3P | 已知 3D 点及对应的 2D 像素 | 本任务没有预先给定的世界坐标点；应先做双图相对几何 |
| 交比 | 同一条 3D 直线上的四个可对应点 | 稀疏、易退化、难自动可靠检测，对不在该直线上的像素完全不起作用 |
| 直接把端点位移叫“光流” | 时间相邻帧、亮度恒常、小运动 | 两张宽基线图的遮挡和透视变化破坏假设；应先恢复几何再导出刚性流 |
| Kalman/粒子滤波 | 状态可预测，并在有真实测量时执行更新 | 中间时刻没有真实测量，只能预测，不能凭生成帧增加证据；而且 ConfCtrl 已占据类似结构 |
| 通用目标跟踪/背景模型 | 连续输入视频 | 本项目要生成这段视频，不能先假定它存在 |
| 类别形状、主动形状模型 | 同类别形状训练库或模板 | 限制开放场景，除非另做建筑部件专项 |
| 单独的平滑轨迹 | 两端相机或用户给定轨迹 | 解决“相机怎么走”，没有回答沿途看见什么；只能是所有方法共用的基础 |

## 6. 自动标注与人工工作量

所有依赖两视图几何的方向都有共同退化条件：未知内参时先只能得到射影关系；完成标定后，平移和深度仍有共同尺度自由度；纯旋转、极小基线、近纯平面、低重叠和重复纹理会让三角化不稳定。系统必须自动输出退化类型和置信度，降低几何注入，必要时退回纯双端生成基线。

默认方案不要求人工标 3D 共线，也不要求逐像素标深度。训练视频中抽取首尾帧作为模型输入，中间真实帧只当监督目标；相机、深度、匹配、遮挡和投影足迹可由三类来源自动得到：

1. **合成数据**：渲染器直接给相机、深度、法线、物体 ID、可见性和表面对应，这是最干净的架构验证集。
2. **带相机的真实视频**：使用数据集姿态或 SfM/SLAM，深度和遮挡用多视图重建生成伪标签。
3. **普通真实视频**：系统只输入抽出的两端 RGB；教师模型自动估计相机、深度和匹配，并用循环重投影、RANSAC 内点和前后遮挡检查过滤低置信样本。

人工只需审核一小批困难样例的类别和失败类型，例如玻璃、镜面、极弱纹理、重复窗格、几何退化和动态物体。若某个实验需要人工画大量直线或逐帧对应，它不适合作为本任务的通用主方案。

## 7. 对实现顺序的约束

先建立只使用两端图的正确 VACE 首尾帧基线，再优先验证 H6、H3；H1 只实现两者所需的最小端点来源选择，并与 GenRec/普通 observable mask 类基线查重。H2、H4、H5 用来验证是否还需要更强的内部几何纠错；H7 独立作为建筑子实验。每次只增加一个模块，并做以下双端因果检查：

- 删除尾图是否明显退化；
- 交换 `I0/I1` 并把时间反转，在相同初始噪声下结果是否相符；
- 把尾图换成同场景错误视角时，路由是否出现冲突而不是忽略尾图；
- 先按只首端可见、只尾端可见、两端都可见和两端都不可见分组，再按两端证据一致度和三维置信度分层测量误差。

这样可以区分“模型真的用了双端物理证据”和“模型只是一个更大的视频生成器”。
