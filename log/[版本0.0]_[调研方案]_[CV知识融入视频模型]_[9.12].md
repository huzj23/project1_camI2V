# 将经典计算机视觉“编译”进扩散模型架构：从 CamI2V 的极线注意力出发

> 如果不熟悉视频扩散、几何或经典视觉，请先阅读[入门简明版](总idea_简明版.md)。简明版逐项说明任务、输入、输出、修改位置、优化目标和算力；本文保留技术细节与查新证据。

> 研究备忘录｜版本：2026-09-10  
> 目标读者：准备立项、复现和投稿的计算机视觉研究者  
> 核心任务：不是再给扩散模型增加一个条件图或辅助损失，而是把经典视觉中的**计算流程、允许的信息通路、状态更新和不变量**写进网络内部。

## 一页结论

最值得做的不是“再造一个极线 mask”，而是把课程中尚未被生成模型充分利用的算法结构变成新的 token 路由或状态更新单元。建议按以下顺序推进：

1. **主线论文：Vote-and-Verify Diffusion Transformer（V²-DiT）**。把广义 Hough 的“局部特征投票”和 RANSAC 的“提出假设—一致性验证—拒绝离群点”变成扩散 Transformer 的中间层。首个任务做**形状保持的轨迹/相机联合控制 I2V**；先用 CamI2V/DynamiCrafter 低成本验证，再迁移到现代视频 DiT。它同时继承课程第 10、11、17、19 章，机制清楚，可做强可解释性实验，检索到的近邻工作只在匹配或位姿估计中做可微 Hough/RANSAC，未发现把完整“投票—假设—验证”循环作为扩散去噪主干路由的高度同构论文。[^hough][^dransac]
2. **高新颖、窄而硬的副线：Rolling-Shutter Ray Attention（RSRA）**。把逐行曝光时间和逐行相机位姿编译为时变曲线对应带，取代全局快门下的一条极线。它是 CamI2V 的自然广义化，但研究问题与普通“球面/鱼眼极线”不同；数据可由 Blender/Unreal 精确合成，结论容易证伪。
3. **低成本保险线：Hysteresis Connectivity Attention（HiCA）**。把 Canny 的强边种子、弱边候选和连通传播变成随扩散时间变化的稀疏注意图；目标不是让输出“边更锐”，而是让轮廓在空间和视频时间上不断裂。
4. **长视频方向：Particle Memory，Kalman 只作高风险基线**。用固定数量的多假设粒子管理遮挡，而非无界缓存所有帧。2026 年 ConfCtrl 已提出 Kalman-inspired predict-update 和 Kalman DiT Block，因此“把 Kalman 更新放入视频扩散”已不能作为新颖主张；只有显式 PSD 协方差、对象级长时状态等明显超出其设定的版本才值得探索。[^confctrl]
5. **三维/光照方向：Integrability Projector Diffusion**。让法向、反照率、光照 token 通过 Lambertian 双线性交互，并在层内投影到近似可积的梯度场；比“把法向图送进 ControlNet”更接近真正的物理架构先验。

“似乎没有人做过”在本文中的严格含义是：截至上述日期，在 arXiv、CVF Open Access 和官方代码库的关键词与引用链检索中，**没有发现高度同构的方法**；这不是法律意义的首创证明。每个想法均标注了最接近先例和撞车风险。投稿前仍应对题名、摘要、Google Scholar/Semantic Scholar 引用链和同期会议稿再做一次查新。

### 1.2 从课程提炼出的八条“研究观”

1. **视觉是带先验的逆问题**。从二维观测恢复形状、运动、材质与光照通常不适定；网络容量并不能取消歧义，只会把未声明的先验藏进数据分布。
2. **局部计算与共享参数是第一层先验**。卷积并非只有“便宜”这一优点，它规定邻域、平移协变性和可组合的感受野；注意力也应被问同样的问题：谁允许看谁，依据什么不变量？
3. **尺度与噪声不可分**。高斯尺度空间、DoG、Canny、曲率尺度空间都告诉我们：粗结构应在高噪声/早期阶段确定，细节在低噪声/后期恢复。扩散时间本身就是可利用的尺度轴。
4. **结构常比纹理可靠**。边缘、角点、骨架、连通分量、凸包和轮廓描述子在光照或外观变化下更稳；生成模型可以先守住拓扑与投影结构，再生成高频外观。
5. **不变量与协变量必须区分**。交比在投影下不变；点、线、极线、法向、光流则按已知规则协变。好的模块不是把这些量全压成一个 embedding，而是保留其变换律。
6. **鲁棒视觉依赖假设与验证**。Hough、RANSAC、PnP 多解、广义圆柱的假设生成/验证都不会一开始就赌单解；扩散模型却常用一次 softmax 把歧义平均掉。
7. **时间模型需要不确定性和记忆管理**。光流有孔径问题和遮挡，Kalman 用协方差决定信任预测还是观测，粒子滤波保留多峰；这比“所有历史帧全注意”更有原则。
8. **物理可分解性比一个标量损失更强**。Lambertian 成像、光度立体、相机投影、可积性约束都给出了变量之间的计算关系；将这种关系放进层内，通常比在输出端罚一次更能限制捷径。

这些观点构成下文的判断标准：一个真正的架构先验，应改变至少一项——**token 的类型、注意力支持集、消息传递方向、状态空间、参数共享方式或层内投影算子**。

## 2. CamI2V 给出的模板，以及不应重复的部分

CamI2V 以 DynamiCrafter 的潜空间视频扩散模型为基座，冻结原模型；将相机射线表示为 Plücker embedding，并在空间注意与时间注意之间插入极线注意。给定两帧相机，基础矩阵限定查询点在另一帧只能沿极线聚合；当视野无重叠时使用 register tokens 兜底。论文在 256×256、16 帧上用 8 张 RTX 3090、有效 batch 64、50k step 训练，并公开 256²/512×320 权重与训练代码。[^cami2v-paper][^cami2v-code]

它给出一个非常好的“编译先验”模板：

```text
几何定律 F x  ->  可计算的支持集 M(x)  ->  稀疏注意力  ->  冻结大基座，只训练新增模块
```

但下列题目已明显拥挤，不宜直接作为主创新：

- 另一个普通全局快门极线 mask：Pose-guided Diffusion、CamCo、CamI2V 和后续多视图方法已有直接先例。[^pose-diff][^camco]
- 仅把深度、点图或 warp 后图像作为条件：像素空间 NVS、WAVE、PointmapDiff 等已覆盖相邻空间。[^pixel-nvs][^wave][^pointmap]
- 仅监督 cross-attention 对齐到对应点：CAMEO 已把对应关系直接用于多视图扩散的 attention supervision。[^cameo]
- 仅把骨架、边缘、法向或拓扑图送入 ControlNet，或只加拓扑损失：骨架引导、SDF 扩散、拓扑生成均有先例。[^humansd][^diffusionsdf][^topocell]
- 泛化的“频域分支”：小波扩散、FAM、FreqFlow、DeCo、Scale Space Diffusion 已构成拥挤赛道。[^wavelet][^fam][^freqflow][^deco][^scalespace]
- 通用 dilation/erosion 扩散层：DEGMC 已用 Riemannian group morphological convolutions 和 convection-dilation-erosion blocks 重构 DDPM 去噪网络。[^degmc]

因此本项目采用更窄的定义：**不是“使用了某种先验”，而是“复现了该经典算法最关键的内部计算语义”。**

### 2.1 六种可复用的先验编译范式

| 课程对象 | 原算法中的关键语义 | 应编译成的网络结构 | 不充分的做法 |
|---|---|---|---|
| Hough / RANSAC | 投票、多个假设、一致性、拒绝离群 | 假设 token、稀疏投票、验证回传、reject token | 输出端 Hough loss |
| Canny / 形态学 | 强弱阈值、连通传播、max/min 半环 | 动态支持图、max-plus/min-plus 分支 | 固定边缘条件图 |
| 骨架 / SDF | 全局拓扑轴 + 局部半径场的对偶 | 图 token 与场 token 双流 | 单张 skeleton map |
| Kalman / 粒子滤波 | 预测—观测更新、协方差、多峰重采样 | 有限状态记忆、PSD 协方差、粒子 token | 拼接全部历史特征 |
| 投影/成像几何 | 不变量、协变关系、曝光模型 | 几何相对位置编码、曲线支持集、可微投影 | 直接回归相机参数 |

## 5. 十五个可形成论文的架构方案

### A1. V²-DiT：把广义 Hough 与 RANSAC 变成扩散的“投票—验证”层（首推）

**任务定义。** 输入首帧、文本、相机轨迹和可选物体稀疏轨迹，生成既遵循镜头运动又保持物体轮廓/部件结构的视频。首篇论文不必解决所有自由度：可以先做刚体或近刚体物体的平移、旋转和尺度变化，再扩到局部平面/3D 运动。

**课程来源。** 第 10 章 Hough 把图像证据累积到参数空间；第 11 章广义 Hough 用 R-table 表示局部梯度方向与参考点之间的关系；第 17/19 章的 PnP、基础矩阵估计体现多解与鲁棒验证。关键不是“Hough 能找直线”，而是**局部证据先对少数全局解释投票，全局解释再选择并组织局部证据**。

**模块。** 在若干中分辨率 DiT/U-Net block 后插入一个双向层：

1. 从参考图提取边/角点 token $r_i=(f_i,p_i,\phi_i,\rho_i)$，其中 $p_i$ 是位置、$\phi_i$ 是梯度方向、$\rho_i$ 是相对参考点的 R-table 描述；当前噪声潜变量的 patch token 为 $x_j^t$。
2. 每个局部 token 不直接全局注意，而是向参数空间中的 $K$ 个**假设 token**投票。最简单参数为 $(c_x,c_y,\log s,\theta)$；相机版本可用局部平面深度/法向或 SE(3) 运动参数。用核化 soft voting 或 log-sum-exp accumulator 保持可微。
3. 假设 token 根据支持残差、外观一致性和可见性得到 consensus score；Top-$K$ 可用 soft top-k/Gumbel 或 slot competition。设置一个显式 **reject/background token** 吸收不支持任何模型的内容。
4. 被保留的假设按其预测变换把 value 反向广播到对应 patch，形成“验证后的稀疏注意”。因此它不是只输出一个姿态，而是直接改变下一层的去噪信息流。
5. 每隔 $L$ 个 block 重做一次投票—验证。高噪声时参数核宽、假设少，先定整体；低噪声时核变窄、允许局部子假设，符合尺度空间思想。

一种抽象写法为：

\[
A_k=\operatorname{LSE}_{i}\left(w_i-\frac{\|h_k-g(r_i,x_i^t)\|^2}{2\sigma_t^2}\right),\qquad
x_j^{t\prime}=x_j^t+\sum_k q_{jk}(A_k)\,V(h_k,r),
\]

其中 $g$ 是由局部证据诱导的几何假设，$q_{jk}$ 同时依赖模型残差和可见性。论文的关键图应把“pixel/patch → hypothesis → verified pixel/patch”画清楚。

**后训练。**

- 阶段 0：冻结生成模型，用 COCO 抠图合成或 Objaverse/Kubric 产生已知刚体变换、遮挡和离群边，单独预训练投票与验证层。
- 阶段 1：在 CamI2V 256²/16 帧设置中冻结原权重，只训练 V² 模块、零初始化输出投影和少量 LayerNorm；主损失仍为扩散噪声/velocity 预测。
- 阶段 2：加入弱监督的一致性损失（假设参数、支持集、跨帧轮廓重投影），但必须报告“无辅助损失”版本，证明收益来自架构而非额外标签。
- 阶段 3：若小模型结果成立，再迁移到视频 DiT，以 LoRA/adapter 而非全量微调开始。

**决定性对照。** 同参数的全局 latent tokens、deformable attention、只加 Hough/RANSAC loss、只有正向投票没有反向路由、随机 R-table、无 reject token、单假设与多假设、固定核宽与 $\sigma_t$ 退火。若 V² 不能显著胜过同 FLOP 的 latent-token baseline，主张即不成立。

**查新风险：低—中。** CHM 已有可微 Hough 匹配，DSAC/∇-RANSAC 已有可微鲁棒估计；新意是把其循环变成视频扩散中反复出现的生成路由层。[^hough][^dsac][^dransac]

### A2. RSRA：滚动快门的逐行时空射线注意（高新颖副线）

**任务。** 给定滚动快门拍摄的首帧/视频、读出方向与相机连续轨迹，生成或校正具有正确视差、弯曲和运动模糊的视频；也可作为“真实手机相机控制 I2V”。

**先验。** 全局快门把一帧视为同一时刻，CamI2V 因而对一帧使用同一外参和一条极线。滚动快门第 $y$ 行的曝光时刻是

\[
\tau(y)=\tau_0+\alpha y/H,
\]

其射线应使用 $T(\tau(y))$。在相机或物体运动下，跨帧允许对应不再由一个固定基础矩阵描述，而是形成与扫描时间相关的曲线/带。

**模块。** 为每个 token 写入 $(o(\tau),d(\tau),\tau)$ 连续射线编码；查询—键相容度由两条时变射线的最短距离、正深度和时间差共同决定。注意力支持为一条有宽度的曲线带，宽度由轨迹/读出时间不确定度预测；无重叠继续使用 register token。进一步可让相机轨迹用 B-spline/SE(3) 控制点表示，网络只学习残差，不任意修改物理轨迹。

**最小实验。** Blender/Unreal 随机室内外场景，逐行精确渲染 global-shutter/rolling-shutter 成对数据；在相同首帧和轨迹下比较无几何、普通 epipolar、每帧单姿态、RSRA。指标包括 row-conditioned reprojection error、直线弯曲误差、相机姿态恢复、LPIPS/FVD，以及误设读出方向的灵敏度曲线。真实数据只做外部验证，不让其标注质量决定首个结论。

**查新风险：低—中。** RS-Diffusion 已用 diffusion 与 patch-attention 做单幅滚动快门校正；其他工作也处理校正/去模糊。当前未发现把逐行相机位姿解析成**受控视频生成的 cross-frame 曲线射线支持集**的同构方法，这才是可守的新意。[^rsdiff][^rs-correction]

### A3. HiCA：Canny 迟滞连通注意

**任务。** 线稿/动画上色、工业零件和人物 I2V 中保持闭合轮廓，抑制视频边缘闪烁、断裂和错误粘连。

**课程先验。** Canny 的核心不是 Sobel 卷积，而是非极大值抑制与迟滞阈值：强边是种子，弱边只有与强边连通才保留。该规则表达了一个明确的条件依赖结构。

**模块。** 从参考图与当前 predicted-$x_0$ 得到梯度幅值/方向，将 token 软分成 strong、weak、off。构建空间 8 邻域加跨帧预测对应的图；strong 节点初始化可达性，weak 节点通过 $L$ 轮 max-plus 消息传递获得可达概率，off 节点阻断。最终可达图作为 attention support，而不是输出端的边缘图。高噪声时高阈值只保留可靠主轮廓，后期降低阈值接入细边；梯度方向还可限制消息沿切线传播、避免横穿边界。

**训练与验证。** 零初始化插入中高分辨率层，冻结基座；不要求真值边，可用参考帧、SAM/边缘教师和跨帧 cycle 产生伪监督。比较 Canny 条件 ControlNet、固定局部窗口、top-k 稀疏注意、输出端拓扑损失和形态学后处理。指标：boundary F-score、断点数、Euler/连通分量误差、跨帧 edge warping error、FVD。

**查新风险：中。** DiffusionEdge 是“用扩散做边缘检测”；DEGMC 则已经把 dilation/erosion 类形态学卷积置入扩散主干。HiCA 只有以 Canny 特有的 strong/weak seed、条件可达性和跨帧时变支持图作为核心，并通过去掉迟滞传播的消融证明机制，才与它们有实质区别。[^diffusionedge][^degmc]

### A4. Kalman-Gain Attention：有协方差的有限状态视频记忆

**任务。** 长时 I2V、相机转回原处、物体被遮挡后再次出现，以及低纹理区域的稳定运动。

**课程先验。** Kalman 滤波不是普通 RNN：预测协方差 $P^-$、观测噪声 $R$ 决定增益 $K$，从而定量决定“信旧状态还是信新观测”。这与扩散每一步观测可靠性随噪声变化天然匹配。

**模块。** 每个物体/区域维护状态 token $(\mu,P)$，状态可包含位置、速度、深度、尺度和压缩外观。时间预测为

\[
\mu^- = A\mu,\quad P^-=APA^\top+Q;\qquad
K=P^-H^\top(HP^-H^\top+R_t)^{-1}.
\]

当前帧潜变量提供观测 $z$，用 $\mu=\mu^-+K(z-H\mu^-)$ 更新；更新后的状态再作为时间注意的 key/value。$Q,R_t$ 由小网络输出 Cholesky/对角正值以保证 PSD，并显式依赖 diffusion timestep：高噪声阶段 $R_t$ 大，更多信任预测；低噪声阶段再吸收细节。遮挡时将观测噪声抬高而非覆盖记忆。

**验证。** 在 Kubric/MOVi 合成遮挡中控制遮挡长度和运动噪声，画出 identity accuracy 与遮挡长度曲线；再在 DAVIS/TAP-Vid 类真实视频做无标注一致性评估。基线必须包括同维度 GRU、普通 memory token、固定门控、无协方差的 EMA 和全部历史 full attention。

**查新风险：高，不能按原样做主线。** ConfCtrl 已提出 Kalman-inspired predict-update，并在每个 Kalman DiT block 中平衡投影点云、相机位姿与生成更新。[^confctrl] 若继续 A4，必须与其代码/公式逐层比较，只保留两种可能的新边界：一是显式可校准的 PSD 协方差而非 confidence map；二是跨很长视频持续存在的 object state，而非双图插值/相机条件融合。否则直接把 ConfCtrl 当 baseline，不把 A4 列为贡献。

### A5. Particle Memory Diffusion：对遮挡和多未来保留多峰假设

**动机。** 单个 Kalman 状态近似单峰高斯；分岔运动、完全遮挡、左右绕行等未来本来就是多峰。softmax 把不同假设平均，常得到身份漂移或不可能的中间运动。

**模块。** 每个 object slot 维护 $K$ 个粒子 token $\{s_k,w_k\}$，各自预测位置/深度/可见性/外观摘要。当前 latent 与粒子计算似然，权重归一化；有效样本数过低时执行 soft resampling，并用可学习过程噪声 mutation。粒子分别路由时间信息，直到生成证据足以合并；遮挡解除时由观测一致性选择分支。为避免算力随视频长度增长，只保留固定 $K$，并允许背景共享少量粒子。

**实验。** 构造“遮挡后左/右出现”“相同外观物体交叉”“相机绕物两侧”等多峰数据；评估 best-of-N 覆盖率、轨迹校准误差、粒子有效数、身份切换和外观一致性。必须比较等计算 mixture-of-experts、随机多 token、beam sampling 和普通 diffusion stochasticity。

**主要风险。** 粒子退化、训练不稳定和 $K$ 倍注意开销。先在低维运动 latent 或 64²/128² toy video 做机制实验，再进大模型。粒子滤波已被用于 diffusion 采样纠错，DiffPF 也以 diffusion 学习粒子 proposal；因此新意必须限定为“对象级粒子作为视频去噪网络的持久内部记忆与路由”，查新风险中—高、工程风险高。[^pf-correct][^diffpf]

### A6. Skeleton–SDF 双流去噪器：全局拓扑轴与局部半径场互相约束

**任务。** 人体/动物/工具的形状保持动画，血管/细胞/道路等细长结构生成，或首帧到视频的部件完整性。

**课程先验。** 骨架给出拓扑和分支关系，距离变换给出到边界的局部尺度；二者合起来近似“轴 + 半径”形状表示。单独骨架缺表面，单独 SDF 容易拓扑变化。

**模块。** 建立两个潜空间：稀疏 medial graph tokens（端点、分叉、边、半径）和稠密 signed-distance/feature field。场 token 只向其半径带内的骨架段查询；骨架节点从对应等距面的 patch 聚合证据。每组 block 依次做 graph update、field update、cross dual update；解码时由半径感知的软 union 重建占据/边界。若任务允许拓扑变化，仅在少数低噪声阶段通过 split/merge token 提案改变图。

**训练。** 首帧骨架可由可微 thinning/现成分割器伪标，后续图由 tracking 传播；医学/合成数据可有真值。比较 skeleton ControlNet、SDF ControlNet、双条件但无双向路由、图-only、field-only、拓扑损失-only。指标为 Betti/Euler、分支召回、断裂率、boundary Chamfer、感知质量。

**查新风险：中。** 骨架条件、骨架 latent diffusion、SDF diffusion 和 topology-aware diffusion 都存在；真正可投稿的部分是“骨架—距离场对偶层”和对 topology/metric 两类误差的机制分解。[^humansd][^diffusionsdf][^topocell][^salad]

### A7. Integrability Projector Diffusion：把光照分解与可积性放进层内

**任务。** 单图可控重光照、相机移动下材质/法向稳定的视频、或多光照条件下的物体 NVS。

**课程先验。** Lambertian 模型把强度分解为反照率、法向和光照；光度立体从多光照恢复法向；形状从明暗还要求法向诱导的梯度场可积。逐像素预测法向而不检查 curl，可能得到无法对应任何表面的“漂亮法向图”。

**模块。** 将中间 token 分为 geometry $N$、albedo $A$、lighting $L$、visibility/specular residual $S$ 四组。主交互使用显式双线性渲染核

\[
\hat I=A\odot \bigl(B(N)L\bigr)+S,
\]

其中 $B$ 可为 Lambertian 点积或低阶球谐。由 $N$ 得到 $p=-n_x/n_z,q=-n_y/n_z$，再用 FFT Poisson 层或少步可微 Jacobi/Helmholtz 投影，将 $(p,q)$ 投影到最近的梯度场；投影残差作为结构 token 回流而不只作为 loss。边界、遮挡和多物体用 mask-aware Poisson 求解。

**实验。** Blender/Objaverse 随机 BRDF 与 HDRI 生成真值法向、深度、光照；先只做 Lambertian，后扩展 specular residual。指标包括 normal angular error、curl/integrability error、relighting LPIPS、跨视角 albedo variance、深度重建误差和通用画质。基线为普通 ControlNet、法向/深度辅助头、仅 integrability loss、无因子 token 的等参 adapter。

**查新风险：中。** 生成式光度立体、法向材质恢复和形状从明暗 diffusion 已有工作；“层内可积投影 + 因子 token 回流”是需要守住的核心区别。[^lightrig][^prm][^sfsdiff]

### A8. CrossRatio Attention：用交比作为投影不变的相对位置编码

**任务。** 大视角差城市/室内 NVS、建筑相机运动、透视显著变化的 panorama/video generation。

**课程先验。** 同一直线上四点的交比在投影变换下保持不变。普通二维 RoPE/绝对位置编码并不尊重该性质，模型需要从数据中重新学透视。

**模块。** 先产生 line tokens 与线上有序 feature points。对候选四点组计算带符号的稳定 log-cross-ratio $c$，跨视图 attention bias 使用 $b_{ij}=-|c_i-c_j|/\sigma$；line token 还保存点序与消失点方向。为避免组合爆炸，只在高置信长线段上采相邻四元组，或由少量 line-hypothesis tokens 预测四元组。可将交比一致的 token 建成 hyperedge，而非两两边。

**关键实验。** 先在纯合成棋盘/立面上训练相同容量模型，系统扫视角、焦距和遮挡，验证外推；再进 Structured3D/建筑视频。对照普通 2D RoPE、homography warp、line condition、VP condition、打乱点序、三点而非四点编码。若优势只出现在训练视角内，说明模型没有利用投影不变量。

**风险。** 同线点检测与排序误差会放大，四点接近时数值不稳；可用不确定度加权和退化 reject token。查新风险低，工程风险较高。检索未发现以交比作为扩散注意相对位置编码的同构工作。

### A9. Vanishing-Point Pencil Attention：沿消失点线束而非规则窗口聚合

给每个 Manhattan/Atlanta 方向一个 VP token；patch 只沿“经过自身且指向该 VP”的射线束做长程 attention，不同方向由软门控混合。平行 3D 线在图像中汇聚，因此这是一种透视协变的轴向注意。目标是建筑/道路/室内视频中的长直线、地平线和透视稳定性。与已有 VP 条件工作相比，贡献必须是**线束支持集**，而不是预测/输入一个 VP。[^controlvp] 对照 axial attention、deformable attention、VP loss-only，并评估 VP error、line straightness、horizon drift 和 FID/FVD。查新风险中。

### A10. EM Plane-Homography Routing：平面专家、软分配与可见性顺序

令 $K$ 个 plane tokens 表示法向/深度，每个专家根据已知相机产生平面诱导单应，把参考 key/value warp 到目标帧；patch 对平面进行软 assignment，交替更新平面参数与成员，形成类似 unrolled EM 的层。加入 z-order/visibility token 决定谁能遮挡谁。它比单 depth warp 更能处理弱纹理墙面，也比一张全局 homography 灵活。已有局部平面、深度/pointmap/warp NVS 很近，因此风险中—高；必须用多平面分配、显式可见性和 EM 迭代做出机制差异。[^lollep][^wave][^pointmap]

### A11. Aperture-Covariance Attention：把光流孔径问题变成各向异性注意核

局部边缘只能可靠约束法向运动，沿切线运动不确定。由结构张量/梯度 Hessian 得到运动协方差 $\Sigma(x)$，把跨帧 attention support 从一个点改为椭圆：法向窄、切向宽；角点近似小圆，平坦区进入 reject/memory token。再用前后向一致性和遮挡抬高协方差，而不是硬信任估计 flow。比较点 flow warp、固定高斯窗口、learned deformable offsets 和等参 uncertainty head。指标除 FVD 外应报告 calibration、NLL、occluded/non-occluded point consistency。普通 flow guidance 已拥挤，但“孔径解析协方差作为生成 attention kernel”查新风险低—中。[^flowvid]

### A12. Delaunay/Voronoi Sparse Attention：由几何邻接替代固定窗口

在角点/关键点 token 上构造软 Delaunay 图，图边表达“局部最近但覆盖全域”的邻接；Voronoi cell 将稀疏结构消息回填到 patch。跨帧用相机/光流预测移动点，再对邻接变化做稳定化。它适合特征分布不均、局部窗口跨过物体边界的场景，也能给每个空洞区域一个最近结构锚点。难点是可微三角化和拓扑跳变；首版可用 kNN 候选 + 空圆判据的软权重近似。查新风险低，工程风险高，宜做小型合成验证后再决定。

### A13. Morphological Lattice Block：max-plus/min-plus 形态学残差支路

在常规线性 attention/MLP 旁加入成对的 dilation/erosion：

\[
\delta_b(x)(p)=\max_{h\in B}[x(p-h)+b(h)],\quad
\varepsilon_b(x)(p)=\min_{h\in B}[x(p-h)-b(h)].
\]

用 softmax/softmin 温度近似，结构元形状可学习但保持成对约束；opening 抑制孤立亮噪，closing 连接小缺口。结构元半径由 diffusion timestep 控制：早期大尺度连接，后期小尺度修边。目标是二值/近二值结构、线稿、细胞和分割到图像生成。**该 idea 原样已不适合独立投稿**：DEGMC 已提出扩散主干中的 group morphological convolutions 与 convection-dilation-erosion blocks。它只能作为 HiCA 的基线/子模块，或进一步限定到随噪声时间变化的成对 adjunction 与视频连通性，且仍属高风险。[^morphdiff][^degmc]

### A14. Curvature-Scale/Fourier Contour Annealing：先低频轮廓，后局部细节

对主要实例维护闭合 boundary tokens，以弧长 $s$ 排序，使用低阶 Fourier 描述子和多尺度曲率 $\kappa(s,\sigma)$。高噪声时仅让低阶模态参与全局路由以固定面积、长宽比和粗轮廓；后期逐步释放高阶模态。可用预测轮廓把 appearance tokens 沿法向窄带对齐，避免跨边界传播。它不同于泛化 frequency branch：频率定义在**对象轮廓参数域**而非整幅图。比较普通频域模块、mask token、active contour loss 和随机模态日程。查新风险低—中，依赖可靠实例边界。

### A15. Occlusion Partial-Order Attention：显式谁挡住谁

为层/对象 token 预测深度区间和可见性，构建有向偏序图：前景可阻止后景内容向当前可见像素传播，但后景身份仍保存在 memory 中以等待 disocclusion。消息分成 transport（只在可见对应上复制）和 hallucinate（对新显露区域生成），并通过可微 z-buffer/soft sorting 融合。课程监控章节对部分/完全遮挡、粒子滤波和多相机地面单应的讨论可直接支撑这一建模。已有深度感知插值与 occlusion-aware propagation，因此新意在扩散层内的**非对称因果可见性图**，风险中等。[^depth-vfi][^occlusion-prop]

## 6. 十五个长尾 idea：适合并入主线、做 workshop，或等待更好任务

| ID | 想法 | 架构化方式 | 最小证伪实验与风险 |
|---:|---|---|---|
| B1 | **GLCM Offset Attention** | 按灰度/特征共现矩阵的方向 $\theta$ 与距离 $d$ 建多头稀疏边；每个 head 对应可解释纹理偏移，而非任意 relative bias。 | Brodatz/DUT texture + 视频材质；比较普通 dilated attention。纹理生成和共现损失先例多，风险中高。 |
| B2 | **Reflectance–Illuminant Color Attention** | 将颜色 token 因子化为反射率与照明色；照明走全局低秩 token，反射率走局部/对象 token，在 log-chromaticity 中相加。 | 合成换光色与真实白平衡；看物体颜色恒常性。Intrinsic decomposition 已有，风险中。 |
| B3 | **Conic-Dual Attention** | 点与圆锥曲线在射影对偶空间交互；ellipse token 通过二次型 $x^\top Cx=0$ 只路由相容边缘。 | 机械孔、车轮、眼睛/虹膜生成；评估椭圆残差。任务较窄但查新风险低。 |
| B4 | **Level-Set Narrow-Band Denoiser** | 只在 $\phi=0$ 附近窄带更新 boundary token，远处走外观分支；拓扑改变由 level-set 自然处理，带宽随扩散时间退火。 | 二值形状到图像与细胞视频；比较 active-contour loss。Level-set diffusion/segmentation 近邻可能多，风险中高。 |
| B5 | **Convex Support-Function Tokens** | 用方向 $u_m$ 上的 support value $h(u_m)=\max_x u_m^\top x$ 表示凸部件；对象由少量凸 token union。 | 工业件/家具旋转 I2V；凸性误差和 silhouette IoU。新颖但对非凸自然物体限制强。 |
| B6 | **Connected-Component Union Tokens** | patch 先产生局部 label proposal，再用可微软 union-find/label propagation 合并；每个 component token 独立保存身份和外观。 | 多相同物体交叉、细胞生成；component 数与 identity switch。与 slot attention 近，风险中。 |
| B7 | **Truncated-Chamfer Boundary Attention** | 查询边缘只在距离变换的截断窄带内匹配参考边缘；方向一致性作为 bias，离群边进入 reject。 | 形变/部分遮挡 object I2V；比较 flow 与 deformable attention。查新低—中。 |
| B8 | **FOE/TTC Radial Attention** | 用 focus-of-expansion token 组织放射流线，注意半径按 time-to-contact 缩放；适合前进相机与驾驶生成。 | 合成道路及 KITTI 类轨迹；TTC/FOE error。任务窄、物体独立运动会破坏假设。 |
| B9 | **Shape-from-Texture Log-Frequency Attention** | 局部纹理频率随透视深度变化；在 log-frequency/方向域沿地平面建立协变消息，估计 slant/tilt token。 | 平面纹理房间/道路 NVS；深度与纹理频率一致性。数据偏置风险高。 |
| B10 | **Structured-Light Code Subspace** | 若输入带投影图案，key/value 只能在已知时空编码子空间交互；解码深度后再指导扩散外观。 | 合成/真实主动深度重建与补全；物理很强但应用窄。 |
| B11 | **Polarization Ambiguity Branches** | Stokes token 经物理 Mueller/DoLP/AoLP 关系生成多个法向歧义分支，再由全局几何一致性选择，不提前平均。 | 偏振物体重建/重光照；需专用数据和传感器，工程风险高。 |
| B12 | **Reject-Option Attention** | 借鉴分类拒绝选项：低置信 query 不强行从错误几何键取值，而转向 prior/register/generative branch；阈值由期望风险校准。 | 系统扫条件噪声与 OOD；看 calibration 与质量—拒绝曲线。单独贡献偏薄，宜并入 A1/A2/A11。 |
| B13 | **PnP Multi-Solution Tokens** | 对对称/弱透视物体保留多个 PnP pose token，直到外观与时间证据消歧；使用解析 solver + soft hypothesis selection。 | 对称物体旋转视频；pose recall@K、身份/纹理一致性。可微 PnP 已有，风险中高。 |
| B14 | **Radial/Fisheye Curved-Ray Attention** | 使用相机模型直接生成单位射线，按球面/广义相机几何构造曲线对应，不先去畸变。 | 鱼眼/360° I2V；边缘区域几何误差。球面极线已有先例，不能只换相机模型，风险高。 |
| B15 | **Scale-Semigroup Block** | 让中间层满足近似 $G_{\sigma_1}*G_{\sigma_2}=G_{\sqrt{\sigma_1^2+\sigma_2^2}}$，并将 $\sigma$ 与 diffusion time 单调绑定；学习非高斯残差。 | 噪声/分辨率外推；做 semigroup violation 曲线。2026 年已有 Scale Space Diffusion，作为独立主张风险高，只宜做 A3/A14 的设计原则。[^scalespace] |

另外两个可随时并入的组件是：以 steerable/group-equivariant kernel 约束旋转协变，以及以傅里叶/小波分支保护频率。但等变扩散和频率扩散都已有成熟先例，不建议把它们单独包装成“无人做过”的标题创新。

## 7. 推荐的完整研究计划：以 V²-DiT 为主，A2/A3 作可转向备份

### 7.1 为什么首选这条线

V²-DiT 同时满足四个条件：

- **课程辨识度高**：Hough、广义 Hough、RANSAC、PnP/基础矩阵的共同方法论都进入了模块，不是引用装饰；
- **与 CamI2V 可直接比较**：同一个冻结基座、数据、分辨率和训练步数，只替换/追加一类信息路由；
- **机制容易被证伪**：投票图、假设纯度、inlier/reject、遮挡长度、离群率都可控；
- **可发展为系列工作**：第一篇做 2D 刚体/轮廓和轨迹，第二阶段做平面/SE(3) 多模型，后续可结合 RSRA 或粒子记忆。

建议论文主张收窄为：

> 扩散视频中的结构一致性，不应只靠逐 token soft correspondence；显式的局部投票、全局多假设和一致性验证能在遮挡、离群边及大运动下提供更可靠的生成路由。

不要把题目写成“经典视觉启发的统一框架”，那会让评审要求所有模块都成立。先用一个结构完成闭环。

### 7.2 基座选择

| 阶段 | 基座 | 选择理由 | 不选择/注意事项 |
|---|---|---|---|
| **P0 机制验证** | 64²/128² 小 DiT 或精简 latent video diffusion | 一张 GPU 快速扫合成离群率、遮挡、运动幅度；允许 50–100 个短实验。 | 结果只能证明机制，不证明真实视频价值。 |
| **P1 主论文基座** | **CamI2V/DynamiCrafter 256²，16 帧** | 官方公开训练、权重、RealEstate10K 预处理与 RotErr/TransErr/CamMC/FVD；冻结基座的设置天然适合增量模块。官方参考训练为 8×RTX 3090、50k step、有效 batch 64，单卡训练显存约 24GB。[^cami2v-paper][^cami2v-code] | 画质和分辨率不是 2026 最前沿；需明确它用于受控科学比较。 |
| **P2 现代转移验证** | **Wan2.1-VACE-1.3B**（R2V）或 CogVideoX-5B-I2V | VACE 官方提供 1.3B、约 81×480×832 的 reference-to-video/control 模型；CogVideoX 官方有 5B I2V。用一个现代 DiT 小规模适配，可反驳“只对旧 U-Net 有效”。[^vace][^cogvideo] | 完整训练支持、具体许可和可改造位置须在开工前复核；5B/81 帧训练成本显著更高。 |
| **不作为首轮** | Wan2.1-I2V-14B | 官方 I2V 是 14B，480P/720P；适合最终展示，不适合用来调通新层。[^wan] | 不要在 14B 上边调 bug 边做消融；先证明机制。 |

结论：**一篇扎实论文不要求从头训练视频基础模型**。最合理的是冻结约 1.4B 的基座，只训练 20–120M 的先验模块；主结论在严格配平的 CamI2V 设置中产生，现代 DiT 只做较小规模 transfer。

### 7.3 数据方案

1. **Synthetic-Vote（自建，机制真值）**：COCO/SA-1B 类前景抠图或 Objaverse 物体，随机平移/旋转/尺度、部分遮挡、重复纹理和 10%–80% 离群边；直接输出真值 transformation、inlier mask、visibility 和轮廓。先做 100k–500k 个 16 帧低分辨率样本，可在线生成。
2. **RealEstate10K（主训练/比较）**：官方约含 10M 帧、约 80k clips 及内外参；CamI2V 论文使用约 70k clips，16 帧、随机 stride 1–10。[^re10k][^cami2v-code] 遵循其 split 与预处理，避免数据差异解释结果。
3. **RealCam-Vid / RealCam-I2V 资源（动态与尺度外测）**：用于评估真实动态场景、绝对尺度轨迹与更复杂相机运动，而非第一阶段依赖。[^realcam]
4. **物体运动补充集**：Kubric/MOVi 生成可控遮挡和多物体身份；真实可用 DAVIS/YTVOS 类 mask 视频提取伪轮廓/轨迹。版权与许可必须逐项记录。
5. **保真数据**：少量无相机标注的公开视频只用于 module dropout/蒸馏，防止模型过拟合静态房地产视频；不让其进入相机控制指标测试集。

数据清洗需保存：视频来源、许可、帧率、分辨率、相机标注质量、动态比例、是否与测试场景近重复。相机轨迹应做坐标系、焦距归一化和异常跳变检查。

### 7.4 模型改造的最小闭环

**版本 V0：2D transformation hypothesis。** 参考首帧提取 R-table；每个目标帧维护 8–16 个 $(x,y,s,\theta)$ token。在 CamI2V 两个中分辨率 block 后插入 V²，模块输出投影零初始化。只训练新增层。

**版本 V1：多对象与遮挡。** 用 4–8 个 object slots，每个 slot 有 4–8 个 pose hypotheses；显式 background/reject；通过 segmentation/track 伪标预热，但主训练可无 mask。

**版本 V2：相机—物体分解。** 全局相机由 CamI2V Plücker/epipolar 路径负责；V² 只解释极线无法解释的 object residual motion。测试“相机静、物体动”“相机动、物体静”“两者均动”三象限。

**版本 V3：局部平面/SE(3)。** 若 V2 成立，再将 hypothesis 参数替换为局部 plane homography 或刚体 SE(3)，不要在第一版同时解决。

实现时保留三个安全阀：

- **zero gate**：新增残差初始为 0，起点严格等于预训练基座；
- **module dropout**：10%–30% batch 关闭先验模块，防止破坏原生成能力；
- **uncertainty/reject**：没有一致假设时退回基座，不强行使用错误几何。

### 7.5 后训练配方

| 阶段 | 可训练参数 | 数据/步数建议 | 目标 |
|---|---|---|---|
| S0 单元预训练 | edge/R-table encoder、vote、verify | 合成 20k–100k step；低分辨率 | 投票峰值、inlier 识别、遮挡鲁棒性 |
| S1 冻结基座 | V² 层 + zero projection + norm | RE10K 5k–15k step 早停 | 验证生成主损失本身能学会使用模块 |
| S2 完整主训练 | 同上，必要时 temporal LoRA | 30k–50k step | 与 CamI2V 官方设置公平比较 |
| S3 任务增强 | 少量 LoRA + condition encoder | 动态/合成混合 5k–20k step | 物体运动、遮挡与 OOD |
| S4 DiT transfer | 只插 4–8 层 + LoRA | 现代基座小规模 2k–10k step | 验证架构可移植性 |

推荐损失为

\[
\mathcal L=\mathcal L_{diff}
+\lambda_h\mathcal L_{hyp}
+\lambda_c\mathcal L_{consensus}
+\lambda_r\mathcal L_{reproj}
+\lambda_e\mathcal L_{entropy},
\]

但 $\mathcal L_{hyp},\mathcal L_{consensus}$ 只在有真值/高可信伪标样本启用；至少报告 `diffusion loss only`、`loss only without V²` 两个关键版本。辅助损失权重先从使各项梯度范数相近的范围起步，再固定，不在测试集挑权重。

## 8. 对比对象、评价维度与验证实验

### 8.1 五层对照，而不是只和一张排行榜比

| 对照层 | 必做对象 | 回答的问题 |
|---|---|---|
| 原始能力 | DynamiCrafter；冻结后不加模块 | 增益是不是只来自继续训练？ |
| 同领域方法 | CamI2V、CameraCtrl/MotionCtrl、可用时的 RealCam-I2V；轨迹控制任务加 Tora 类方法[^tora] | 是否比已有相机/轨迹控制更好？ |
| 同容量结构 | 全局 hypothesis-like latent tokens、局部窗口、deformable attention、Mixture-of-Experts | 是否只是多了参数/FLOP？ |
| 同先验不同注入 | 条件图/ControlNet、输出端 loss、采样期 guidance、后处理 Hough/RANSAC | 架构注入是否优于条件或损失？ |
| 上界/下界 | 真值变换/可见性 oracle；随机 R-table；打乱假设；错误轨迹 | 模块到底使用了什么信号，失败边界在哪？ |

所有模型应共享训练数据、采样器、步数、CFG、输入帧和随机种子；报告新增参数、训练 FLOP、峰值显存、推理延时。对于稀疏 attention，既报告理论复杂度，也报告真实 wall-clock，因为不规则 kernel 可能没有实际加速。

### 8.2 指标不应只剩 FVD

| 维度 | 指标/诊断 | 说明 |
|---|---|---|
| 通用视频质量 | FVD（至少两种 feature backbone）、VBench 子项、CLIP/text alignment、人评 | 防止几何变好但画质崩坏；FVD 实现差异要固定。 |
| 相机控制 | RotErr、TransErr、CamMC、VGGSfM/Colmap pose success、轨迹 ATE | 直接沿用 CamI2V 官方协议，并加重建成功率。 |
| 结构/外观一致 | DINO/CLIP feature consistency、CoTracker track survival、LPIPS warp error、identity similarity | 区分纹理复制、几何对应和语义身份。 |
| 轮廓/拓扑 | boundary F-score、Chamfer、断点数、Euler characteristic、Betti/分支召回 | A3/A6/A13/A14 的主指标。 |
| 假设机制 | pose recall@K、accumulator peak ratio、inlier precision/recall、reject calibration、hypothesis entropy | V² 的可解释证据，必须进入正文。 |
| 遮挡与不确定性 | identity switches、occlusion-length curve、NLL/ECE、coverage vs. particle count | A4/A5/A11/A15 的主指标。 |
| 计算 | trainable params、TFLOPs、VRAM、steps/s、sampling latency | 与同容量结构配平。 |

避免只用模型自己产生的深度/光流再评自己。主结论至少包含一套合成真值指标、一套相机/SfM 几何指标和一套感知质量指标。

### 8.3 主论文实验矩阵

| 实验 | 设置 | 期望回答 | 失败判据 |
|---|---|---|---|
| E0 单元测试 | 64² 合成刚体；扫离群率 0–80%、遮挡 0–80% | 投票峰与正确假设是否仍可分？ | 不优于等参 MLP/attention，立即重构或停线。 |
| E1 受控生成 | 合成 16 帧；已知变换、轮廓、可见性 | V² 是否改善结构而不牺牲画质？ | 仅辅助 loss 有效、关掉架构无变化。 |
| E2 RE10K 主结果 | CamI2V 256²/16 帧官方 split | 对相机控制与 FVD 是否至少不退化？ | 置信区间显示 FVD/相机指标稳定变差。 |
| E3 动态三象限 | camera-only / object-only / both | 是否真正分开全局相机与局部运动？ | 只在 camera-only（训练偏置）有效。 |
| E4 鲁棒性曲线 | 错边、重复纹理、条件噪声、视野无重叠 | 多假设/reject 是否是增益来源？ | 随机 latent tokens 同样好。 |
| E5 OOD | 插画、室外、复杂遮挡、不同焦距 | 是否比基座少过拟合？ | 仅房地产室内有效且机制指标失灵。 |
| E6 现代 DiT 转移 | VACE-1.3B 或 CogVideoX-5B-I2V，小规模 adapter | 是否不是 U-Net 特例？ | 可以报告负结果，但主张要收窄。 |
| E7 用户偏好 | 同 prompt/图/轨迹盲测 | 结构改善是否可感知？ | 几何指标提升但人评无差异，应用主张降级。 |

统计上至少做 3 个训练种子用于核心消融；测试按同一输入、同一采样 seed 成对比较，用 bootstrap 95% CI。先注册主指标与容忍区间，再看结果，避免从几十个指标中挑最好看的一个。

### 8.4 必须画出的机制图

1. 随扩散时间变化的 accumulator：早期应出现粗而少的峰，后期峰变尖；
2. 正确/错误假设的 consensus 分布及 reject 概率；
3. 遮挡与离群率二维热图；
4. 查询 patch → hypothesis → 反向路由 patch 的可视化；
5. 打乱 R-table、交换梯度方向或给错误相机轨迹时，性能应按可解释方式下降；
6. 等参数 generic token 不产生同样集中、可校准的峰。

## 9. 一般研究范式：以后每个课程先验都按这个流程做

```text
课程算法
  ↓ 找出不可替代的计算语义（不是名称）
变量与变换律
  ↓ 哪些是不变量、协变量、不确定量、离散拓扑？
编译接口
  ↓ token 类型 / 支持集 / 有向消息 / 状态更新 / 投影层
合成最小世界
  ↓ 有真值、可扫违例程度、能在一周内推翻
冻结基座的等参实验
  ↓ 排除数据、参数量、继续训练和辅助损失
真实数据与 OOD
  ↓ 验证不是玩具假设
再扩大模型
```

具体要遵守六条纪律：

1. **先写失败条件。** 例如交比要求可靠共线四点，Lambertian 在强镜面下失效，Kalman 假设近似单峰；网络必须能检测并拒绝，而不是暗中违反物理。
2. **先做可逆小改动。** 新模块残差零初始化，冻结基座；这样负结果不会消耗一次完整预训练。
3. **匹配容量和信息。** 与通用 attention 比时，参数/FLOP/输入条件必须相同；与 loss-only 比时，几何标注也相同。
4. **把先验强度变成可扫变量。** 支持带宽、假设数、协方差、形态学温度、Poisson 迭代数都要可控，画性能—约束强度曲线。
5. **让物理失配可回退。** register/reject/generative token 是先验系统的一部分，不是补丁；硬先验若无回退会在动态物体或 OOD 上灾难性失败。
6. **机制指标先于 SOTA。** 先证明模块确实执行了投票、连通、协方差或投影，再讨论 FVD 小数点。

### 9.1 Idea 选择的三道闸门

- **Gate 1（1–2 周）**：最小合成任务相对等参通用层，在目标物理误差上有稳定、随违例强度可解释的改善；否则停。
- **Gate 2（4–8 周）**：冻结 CamI2V 后，至少一个结构/控制主指标有实质改善，而 FVD/文本一致性不出现统计显著退化；否则改为 workshop 或转 A3。
- **Gate 3（10–14 周）**：真实/OOD 和第二数据域仍成立，并且 loss-only/condition-only 不能解释增益；否则收窄任务或转 RSRA 这种物理边界更清楚的方向。

建议的内部硬门槛（可在开工前根据 baseline 方差调整）是：E0 在 50% 遮挡或 50% 离群率时，目标几何误差相对等参 attention 降低至少 15%–20%；E2 结构主指标改善至少约 8%–10%，同时通用质量落在基座 95% CI 或更好。门槛是止损工具，不是投稿时选择性报告的规则。

## 10. 论文级工作量、算力与工程预算

### 10.1 建议人员与周期

一篇完整主会论文，现实配置为 **1 名主力研究者 + 0.3–0.5 名工程/导师支持，18–24 周**：

| 周 | 交付物 |
|---:|---|
| 1–2 | CamI2V 官方权重/评测复现；合成生成器；查新表冻结 v1 |
| 3–5 | V² 单元层、梯度检查、E0 鲁棒性曲线 |
| 6–8 | 插入 CamI2V、5k–15k step 冻结训练、首次等参对照；Gate 2 |
| 9–12 | 30k–50k 主训练，数据清洗与核心指标 |
| 13–16 | 结构消融、遮挡/OOD、三种子关键结果 |
| 17–19 | 现代 DiT 小规模迁移或 RSRA/HiCA 补充；人评 |
| 20–22 | 图表、论文、代码整理；同期工作二次查新 |
| 23–24 | rebuttal 预演、补最危险对照、发布模型卡/数据说明 |

不要把所有 30 个 idea 都实现。合理的一篇论文工作量是：**1 个主模块 + 1 个回退/不确定性组件 + 1 个现代基座转移**。A3、A11、B12 可以作为 V² 的小组件，但不能都宣称独立贡献。

### 10.2 单次训练资源

CamI2V 官方事实基线是：256²、16 帧、50k step、8×RTX 3090、有效 batch 64，训练约需每卡 24GB；推理约 12GB。[^cami2v-paper] 官方没有给出可普遍复用的 wall-clock，因此不应伪造精确小时数。

先在目标机器上跑 500–1,000 step，按下式预算：

\[
\text{GPU-hours}=N_{GPU}\times N_{steps}\times \frac{\text{seconds/step}}{3600}\times 1.3,
\]

其中 1.3 覆盖验证、保存和故障。若 8 卡实测为 2–6 秒/step，则一次 50k run 约 **290–870 GPU-hours**（仅为容量规划范围，不是论文报告值）。V² 的目标是新增参数 20–120M，额外 FLOP/延时控制在 5%–20%；若超过 30%，需有明显质量收益。

### 10.3 三档总预算

| 档位 | 硬件 | 总训练预算 | 能完成什么 |
|---|---|---:|---|
| 最小可行 | 1–2×4090/3090 24GB | 150–400 GPU-h | E0、单元预训练、5k–10k CamI2V 冻结 adapter；足以决定继续/停止 |
| 主会论文 | 8×24–48GB GPU（或 4–8×A100 40/80GB） | **2,000–5,000 GPU-h** | 1–2 次 50k 主训练、三种子关键缩小实验、8–12 个 5k–15k 消融、OOD 和完整评测 |
| 强化版 | 上述 + 8×A100/H100 80GB 短租 | 4,000–9,000 GPU-h | 再加 VACE-1.3B/CogVideoX-5B-I2V transfer、81 帧或 480P 结果 |

14B I2V 不在核心预算内；除非已有 8×H100 80GB 和成熟训练栈，否则只做推理展示，不能让主结论依赖它。

### 10.4 非 GPU 资源

- **存储**：原始/裁剪视频、合成缓存、光流/边缘/相机伪标、checkpoints 与生成结果合计预留 3–8TB；热数据最好 NVMe。
- **CPU/RAM**：数据预处理建议 32–64 CPU cores、128–256GB RAM；视频解码常会先于 GPU 成为瓶颈。
- **运行数**：约 1 次官方复现、2–4 次主训练、8–12 次缩小消融、6–10 次鲁棒性短训、1–2 次现代迁移；不要把每个消融都跑 50k。
- **评测样本**：主表每方法至少 1k–2k 条配对生成；最重要的 200–400 条做多 seed 与盲人评。提前估算推理 GPU-hours。
- **可复现性**：锁定 commit、conda/pip lock、数据 manifest、随机 seed、坐标系约定和评测容器；保存每次 run 的 trainable parameter list 与真实吞吐。

## 11. 如何包装成一篇清楚的论文

### 11.1 题名与贡献

可用题名：

- **Vote, Verify, Then Denoise: Hypothesis-Routed Diffusion for Structure-Consistent Image-to-Video Generation**
- **V²-DiT: Generalized-Hough Hypothesis Tokens for Robust Image-to-Video Diffusion**
- 若最终以相机—物体分解为主：**Beyond Epipolar Attention: Vote-and-Verify Routing for Dynamic Camera-Controlled Video Diffusion**

只声明三项贡献：

1. 一个把局部投票、多几何假设、一致性验证和反向内容路由统一起来的扩散层；
2. 一个专门考察遮挡、离群边、重复纹理和相机/物体混合运动的合成—真实评测协议；
3. 在冻结 CamI2V 和一个现代视频 DiT 上，证明该计算结构优于同信息、同容量的 condition/loss/generic-attention 方案。

不要把边缘提取器、Gumbel top-k、slot 初始化、辅助 loss 都列成贡献。评审真正要判断的是“假设空间是否是一种更好的生成信息瓶颈”。

### 11.2 正文图表最小集合

- **Fig. 1**：CamI2V 的 pixel→epipolar-line 与 V² 的 evidence→hypotheses→verified support 对照；
- **Fig. 2**：完整架构与一个 V² block 放大图；
- **Fig. 3**：合成离群率×遮挡率热图和 accumulator 可视化；
- **Fig. 4**：真实视频定性，突出轮廓、身份、遮挡再现和相机运动；
- **Table 1**：CamI2V 官方协议主结果；
- **Table 2**：同参数结构、condition-only、loss-only、post-hoc 对照；
- **Table 3**：假设数、reject、kernel schedule、层位置、监督来源消融；
- **Table 4**：现代 DiT transfer、FLOP/显存/延时。

### 11.3 最可能的评审质疑与预先回答

| 质疑 | 需要的证据 |
|---|---|
| “只是多了 object tokens。” | 等参 latent-token baseline；打乱 R-table 后下降；可视化投票峰与 inlier。 |
| “收益来自额外边缘/姿态标签。” | 相同标签的 condition/loss-only；diffusion-loss-only 的 V²。 |
| “Hough/RANSAC 早已可微。” | 坦率引用 CHM/DSAC/∇-RANSAC；贡献定位在生成去噪的双向反复路由。 |
| “只在静态 RE10K 有效。” | 动态三象限、合成真值、RealCam-Vid/OOD；报告动态物体失败例。 |
| “旧基座结果不代表现代模型。” | 一个现代 DiT 的小规模转移；若失败则把主张限定在 latent U-Net。 |
| “物理先验会妨碍 hallucination。” | reject/register、module dropout、错误条件曲线和通用质量 CI。 |
| “稀疏操作理论快、实际慢。” | 真实吞吐和 kernel profiling，不只给复杂度。 |

### 11.4 值得主动报告的负结果

- 硬 top-1 假设在对称物体上平均/跳变；
- 没有 reject token 时，大遮挡或视野无重叠导致错误复制；
- 全分辨率都插 V² 可能放大边缘噪声，中分辨率插入更稳；
- 只有 Hough loss 而无反向路由可能改善 pose 指标但不改善生成；
- 过强 early-edge prior 可能抑制新显露区域和非刚体细节；
- 现代 DiT 中新增不规则 sparse kernel 的 wall-clock 未必优于 FlashAttention。

这些不是“坏消息”，而是说明先验边界、使论文可信的机制发现。

## 13. 按现实资源选择方向

| 现有条件 | 最优选择 | 原因 |
|---|---|---|
| 只有 1–2 张 24GB GPU、目标是快速产出 | **A3 HiCA；A13/DEGMC 作基线** | 模块轻、可在边界/线稿数据上快速证伪，训练无需相机标注。 |
| 有 CamI2V 环境和 8 张 24GB GPU | **A1 V²-DiT** | 最能利用现有项目、官方评测和课程特色，论文叙事最完整。 |
| 有图形学渲染能力或手机滚动快门数据 | **A2 RSRA** | 物理定义最硬、查新风险低、合成真值精确。 |
| 有长视频/跟踪积累 | **A5 Particle Memory；A4/ConfCtrl 作 baseline** | 多峰重采样更有差异；避免与已有 Kalman DiT 正面同构。 |
| 有法向/材质/HDRI 数据或 3D 团队 | **A7 Integrability Projector** | 物理可解释强，容易设计定量真值实验。 |
| 目标是最大新颖性且可接受高失败率 | **A8 交比、A12 Delaunay** | 检索空白较大，但前端检测和可微离散结构难。 |

我的最终建议是：**先用两周做 V² 的 E0，同时用极小成本实现 HiCA 作为保险。** E0 过 Gate 1 就把资源集中到 V²；不过则不要在大模型上赌，转 HiCA 或数据条件允许时转 RSRA。

## 14. 局限、伦理与开放科学

- “物理先验”只在其假设成立时正确。动态非刚体、镜面、透明、滚动快门参数错误、伪边缘都会造成系统性偏差；论文需展示失配曲线与回退机制。
- RealEstate10K 偏静态室内/房地产，相机姿态由 SLAM 得到且尺度可能不一致；不能把该数据上的成功等同真实动态世界。RealCam-I2V/RealCam-Vid 正是针对绝对尺度与动态场景的后续补充。[^realcam]
- 课程的人脸与监控部分提醒：更稳定的身份/跨遮挡生成也可能加强冒用与监控能力。发布时应给身份保真风险说明、水印/溯源建议，并避免未经同意的人脸训练/演示。
- 所有第三方视频、预训练权重和伪标模型要记录许可；论文开放代码时发布配置、数据索引与合成器，不重新分发无权分发的视频。
- “未发现同构工作”应随投稿日期更新。尤其 CVPR/ICCV/arXiv 在 2026 年增长很快，查新结论会过期。
