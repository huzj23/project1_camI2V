## 新颖性核查记录与剩余不确定性

核查日期为 2026-09-13。采用“教材机制词＋生成任务词＋架构词”的组合寻找直接近邻，再阅读作者论文／项目／代码。生成式 diffusion 与传统偏微分方程中的 diffusion 需要区分；数学扩散方程的同名搜索结果不能算生成模型近邻。

| 检索簇（代表性关键词） | 核查到的关键近邻 | 对筛选的影响 |
|---|---|---|
| epipolar attention / camera video diffusion | [CamI2V][R07]、[EpiDiff][R08]、[SPAD][R09] | 对极注意力本身归为基线 |
| correspondence attention / aligned regions / diffusion adapter | [CorrAdapter][R12]、[CAMEO][R13] | N02／N06／N07 必须超过普通匹配聚合和对应监督 |
| normal depth / joint geometry / novel view diffusion | [Wonder3D][R23]、[GeoWizard][R24]、[MVGD][R25]、[MoAI][R14] | N03 不能只增加几何输出或跨模态注意力 |
| anti-aliasing / fractional shift / video diffusion / footprint | [AF-LDM][R22]、[mip-NeRF][R21] | N01 区分采样足迹、匹配不确定性及一般低通 |
| affine regions / canonicalization / novel view | [AffNet][R19] 等学习局部区域工作 | N02 的仿射估计器本身没有新颖性 |
| optimal transport / dustbin / feature matching | [SuperGlue][R20] | N06 不以 Sinkhorn／未知槽本身申报创新 |
| optical flow / camera-controlled video synthesis | [FloVD][R16]、[Motion-I2V][R42] | N05 的贡献必须来自内部刚性约束而非光流条件 |
| confidence / first last frame / interpolation | [ConfCtrl][R11]、[KFC-W][R39]、[Generative Inbetweening][R41] | N15／N17 及整个任务已有强近邻 |
| Gaussian scene representation / video diffusion | [GGS][R15]、[GaussVid][R46] | 显式三维中间表示不是尚无人探索的结构位置 |
| lens distortion / optical video generation | [AKiRa][R17] | N18 的参数条件与射线控制已有方案 |
| reflectance / intrinsic decomposition / lighting video | [GS-ID][R29]、[LiVER][R28] | N11 的材料／光照分解必须限定新问题 |
| vanishing point / diffusion generation | [ControlVP][R30]、[PRoPE][R43]（相机位置编码近邻） | N10 不是“首次使用消失点／相机方向” |
| occlusion / memory / video generation | [MemLearner][R31]、[VODiff][R32]、[SeeThrough3D][R33] | N04／N17 需区分边缘来源、身份与可见性状态 |
| morphological / diffusion / video | [Rethinking 3D Noise][R34] | 形态扰动的数据训练策略与 N14 内部传播区分 |
| conic / contour / novel view diffusion；MSER / diffusion | 找到轮廓／结构控制邻域工作，未确认 N09／N13 的直接同构方案 | 证据较弱：保留为受限探索，不据此宣称首创 |
